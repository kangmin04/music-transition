# 로컬 테스트 방법 (Phase 1: 브라우저 탭 ↔ 탭 버전)

1. Chrome에서 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`music-transition/chrome-extension`) 선택
4. 탭 A: 유튜브 등에서 강의 영상 재생
5. 탭 B: YouTube Music, Spotify Web Player 등 원하는 음악 사이트에서 아무 곡이나 재생
6. 확장 아이콘 클릭 → 팝업에서
   - 탭 A로 이동 후 "현재 탭을 강의 탭으로 지정"
   - 탭 B로 이동 후 "현재 탭을 음악 탭으로 지정"
7. 탭 A에서 영상을 pause(스페이스바든 마우스 클릭이든 상관없음) → 탭 B가 지정한 볼륨으로 자동 재생되는지 확인
8. 탭 A 영상을 다시 재생 → 탭 B가 자동으로 멈추는지 확인

## 알려진 제약

- 음악 탭을 새로고침하거나 다른 URL로 이동하면 주입된 콘텐츠 스크립트가 사라집니다. 다시 "현재 탭을 음악 탭으로 지정"을 눌러야 합니다.
- 강의 영상 시크(앞뒤로 드래그) 중 발생하는 짧은 pause/play 오탐은 400ms 디바운스로 걸러집니다. 다만 유튜브 광고 전환처럼 pause 상태가 400ms보다 오래 지속되는 경우는 여전히 음악 재생을 유발할 수 있습니다.
- Spotify Web Player처럼 재생에 DRM(EME)이 관여하는 사이트는 `video.pause()`/`.play()` 호출이 내부 UI 상태와 완전히 동기화되지 않을 수 있습니다. 문제가 확인되면 버튼 클릭 시뮬레이션 방식으로 보강할 예정입니다.
